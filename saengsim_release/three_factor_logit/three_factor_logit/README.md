# 세 가지 통시 로짓 모형

이 디렉터리에서는 세 가지 선형 시간 시험모형을 별도로 적합한다. 의문문은 ‘（수사）의문문’으로 통일하여 표시한다. 이번 M1—M3 번호는 이전 M1—M4 번호와 구별된다. M1과M3은 일부 목표용례를 공유하므로 독립적인 반복증거가 아니다.

`y_j ~ Binomial(n_j, p_j)`

`log(p_j/(1-p_j)) = a + b*t_j + u_document(j)`

`t_j = (year_j-1750)/20; u_document ~ Normal(0, sigma_document^2)`

문형과 검정별로 계수를 별도 추정한다. 20년은 시간 단위일 뿐, 자료를 20년 구간으로 묶지 않는다. 변곡점은 추정하지 않는다.

M1/M3은 수정된 목표 용례표에서 대표연도가 있는 1500—1955년의 해당 문형을 사용한다. 원자료 분석ID와 원판정은 보존하며 출력의 괄호 표기만 통일한다.

M2 주분석은 명시 단일년 문헌에 연구자가 지정한 18세기 서궁일기(대표1750.5)를 추가한 후보구간 자료이다. 계축일기는 목표표에서18세기로 유지하되 전말뭉치 목록에 같은 제목이 없어 분모를 만들지 않는다. 혼합연대 언간자료K0228은 통째로 제외한다. 검토된16구간으로 전체 자료의 연대를 대체하지 않는다. 생심도 원번호163은16세기 후반 대표1575.5로 수정되었다.

M2 민감도 분석은 자료층 통제(`_source`, 우변에 cL 추가, L=대역1/기타0), 기존 명시 단일년만 사용(`_metadata`), 대표연도 추정자료 확대(`_expanded`)이다. 후자 둘은 공통 함수를 유지한다. 기존 M4 연구자 연대보완 자료를 재사용하며 추출기를 새로 학습하지 않는다.

베이지안 문헌 무작위절편 이항회귀를 사용한다. 절편 사전분포의 중심은 전체 비율로 보정하며 시간기울기는Normal(0,0.6), 문헌 표준편차는HalfNormal(1)이다. 4체인별2000워밍업+2000사후추출을 수행한다. 결과는 중앙값과95%등꼬리 신용구간이며 빈도주의 p값이 아니다. Rhat·ESS·발산을 점검한다.

OR20=exp(b)이다. b<0은 해당 비율의 시간적 감소를 뜻한다. M1은 내부 구형식 점유율, M2는 자동 분류된 해당 문형 후보 구간에서 DARE 부사어가 출현한 비율, M3은감히 대비생심류 점유율의 감소 근거이다. 분모와 관측단위가 달라 OR크기로 원인의 강도를 직접 순위화하거나 인과적 교체를 증명할 수 없다.

M2 의문후보는 수사/진성의문을 신뢰성 있게 구분하지 않아 통합표기를 사용한다. 의미적으로 DARE가 허용되는 모든 기회를 포착한 것은 아니다. M2의 문형 후보 구간은 자동 분류 결과에 기반하며, 전체 구간에 대한 연구자의 수동 검토가 완료된 정답 자료(gold standard)는 아니다. 문형 오류·시대별 장르 구성·연대 추정 및 대표연도 부여의 불확실성·희소성은 해석을 제한하며 문헌절편으로 시대와 장르의 혼재가 완전히 해소되지 않는다. M1/M3 목표표와 M2 전말뭉치 추출은 자료범위가 달라 비율을 직접 곱하여 빈도를 분해할 수 없다.

입력 집계표·한국어 결과CSV·모수별 진단은 본 디렉터리에 저장한다. 대용량 사후.nc는Git에 넣지 않으며 고정seed로 재실행할 수 있다.

연구자 요청에 따라 생심도에 N=단순부정문, PN=부정명령문+단순부정문 분석을 추가하고 기존 Q/P를 유지한다. M1=생심도/생심류 전체, M2=DARE 포함 후보 구간/해당 범위 전체 후보 구간, M3=생심류/(생심류+감히)라는 비율 정의를 유지한다. M3을 생심도 대 감히로 바꾸지 않는다.

N의 목표 용례는 기존 판정표를 그대로 사용한다. M2의 N 분모는 제공된 `data/audit_population.csv.gz`의 기존 분절·중복 제거를 유지하고 ‘기타’ 구간에 부정 표지 규칙을 적용한다. -지/-디/-티/-치+아니/않/못/몯 및 독립 단형 부정 아니·못·몯·안을 인식하며 기존 Q/P/P_모호와 금지·명백한 부정 사동을 제외한다. 목표 형식 유무와 무관하게 같은 규칙을 적용한다. 종속절 부정이 있는 구간도 포함되므로 주절·DARE 작용역을 완전히 복원한 판정은 아니다. 역사 표기·의미적 중의성을 망라하지 못하는 자동 후보이다. 정확한 정규식과 출처 해시는 `data/negative_provenance.json`에 있다.

N에도 세 가지 연대 범위와 자료층 통제를 적용한다. 목표 형식 포함100예·미포함100예의 층화 검토 CSV를 추가한다. 연구자 검토 전이며 완료된 수동 정답 자료로 사용하지 않는다.

세 문형 통제 모형에 더 좁은 c~Normal(0,1.5)도 비교했다. 방향은 같지만 M3은 넓은 사전분포에서95%구간이 무변화 경계에 더 가까워 경쟁의 제한적 근거로 해석한다. 여섯 행의 비교표는 `results/문형통제_사전민감도.csv`이며27개 주실행·연대 대조 모형 수에 중복 계산하지 않는다.

PN의 문형 미통제 모형은 두 문형 합계의 주변 비율을 추정하므로 문형 구성비 변화에 영향을 받을 수 있다. `_type`은 `log(p/(1-p))=a+b*t+c*I(N)+u_document`, I(N)=단순부정1/부정명령0, c~Normal(0,3)을 적합한다. 넓은 사전분포로 문형 간 큰 기준 차이를 허용하되 시간 기울기는 공통으로 가정한다. 합계만 명확하고 분리·문형 통제 결과가 불확실하면 합계 감소를 감히 경쟁으로 직결하지 않는다. M1_N은10예 중 생심도8예에 불과하여 희소성·사전분포·귀년에 특히 유의한다.

## 실행 및 자료 위치

저장소 최상위에서 `cd saengsim_release/three_factor_logit`를 실행한 다음 아래 명령을 사용한다. `requirements.txt`에 명시된 의존성 버전을 설치한 별도 Python 환경이 필요하다.

```sh
python3 -m pip install -r three_factor_logit/requirements.txt
python3 three_factor_logit/src/rebuild_qp.py  # 선택: Q/P 후보 재생성
python3 three_factor_logit/src/add_negative.py  # 선택: N 후보·집계 재생성
python3 three_factor_logit/src/validate_inputs.py
python3 three_factor_logit/src/run.py
python3 three_factor_logit/src/report.py
```

`src/rebuild_qp.py`는 공개된 `audit_population.csv.gz`에서 Q/P 후보를 재구성하고 문헌별 집계가 `M4_QP_연구자보완.csv`와 완전히 일치하는지 확인한다. `src/add_negative.py`는 같은 모집단과 `document_metadata_corrected.csv`를 이용하여 N 후보와 연대별 집계표를 재생성한다. 이 두 재추출 단계는 모형 재적합 전에 선택적으로 실행할 수 있다. 다만 최초 말뭉치 분절·자동 문형 분류의 생성 코드는 이 공개본에 없으므로 원말뭉치부터의 완전한 재생성은 별도 작업이다.

모형 입력은 적합 당시의 판정 스냅샷이며 전처리 표의 후속 수정과 구별한다. 원본 목표 용례 통계표는 `../원시자료/원시자료/감히, 생심 말뭉치 통계.xlsx`에 있다. 원말뭉치 원본 파일 전체는 제공하지 않으나, 자동 분절된 후보 구간 원문 자료는 별도로 포함한다. 입력 집계표로 모형을 재적합할 수 있으며, 제공된 후보 모집단에서 Q/P/N 후보를 재구성할 수도 있다. 다만 원말뭉치에서 최초로 자동 분절·문형 분류하는 과정은 재현 대상에 포함되지 않는다.

## 자동 후보 구간과 자료 계보

- `data/audit_population.csv.gz`: 자동 분절·자동 문형 분류된 전체 후보 구간의 모집단(624,722구간). 4,000개 층화 추출 표본 자체가 아니며, M2 주분석의 최종 분모도 아니다.
- `data/QP_candidates.csv.gz`: M2 주분석에 포함된 의문문(Q, 19,217구간·DARE 포함 344구간)과 부정명령문(P, 3,167구간·DARE 포함 22구간)의 구간별 원문·식별자·연대·자료층·목표 형식 포함 표시. `data/QP_candidates_provenance.json`은 추출·귀년·계수의 계보를 기록한다. `src/rebuild_qp.py`로 문헌별 집계의 완전 일치를 검증한다. 해당 파일은 추적·검토용이며 현재 `src/run.py`의 직접 입력은 아니다.
- `data/negative_candidates.csv.gz`: `src/add_negative.py`로 재생성할 수 있는 일반부정문(N)의 자동 후보 구간(확대 연대 범위 포함). 주분석 N 분모와는 범위가 다르며 추출 규칙은 `data/negative_provenance.json`을 참조한다.
- `data/M4_QP_연구자보완.csv`, `data/M2_N_연구자보완.csv`: M2 주분석에 실제로 투입되는 문헌·연대별 집계 자료. `_metadata`와 `_expanded`는 연대 범위의 민감도 분석, `_source`는 자료층 통제 모형이다.
- `data/annotated_G_date_corrected.csv`: M1·M3의 목표 용례 분석에 사용하는 적합 당시 판정 스냅샷이다. `data/input_*.csv`는 각 모형에 사용된 집계 입력이다.

위 후보 구간의 문형은 자동 추출·자동 분류 결과로, 개별 구간에 대한 연구자 수동 검토가 모두 완료된 정답 자료(gold standard)가 아니다. 특히 의문문 후보는 수사의문문과 진성의문문을 분리하지 않는다. M2의 분모는 의미·화용적으로 DARE 사용이 가능한 모든 기회를 뜻하지 않는다. 4,000개 층화 표본은 이 모형의 적합·분모 보정에 사용하지 않았다.

## 모형별 확률의 정의

|모형|성공 확률의 정의|
|---|---|
|내부 교체|의문문에서는 생심이나, 부정명령문·단순부정문에서는 생심도가 생심류 전체에서 차지하는 비율|
|사용 환경|자동 분류된 해당 문형 후보 구간 중 감히 또는 생심류를 포함한 구간의 비율|
|상대 점유율|해당 문형의 감히와 생심류 전체 중 생심류가 차지하는 비율|

각 모형의 매개변수는 별도로 추정한다. 절편 사전분포는 전체 비율을 중심으로 한 표준편차 3의 정규분포이며 자료층 계수는 표준편차 1.5의 정규분포를 따른다. 무작위 시드는 20261116이고 목표 수용률은 0.99이다. `data/unit_index_labels.csv.gz`는 후보 문형의 상호배타성 검증용 식별자 색인이다. 진단 파일은 `results/모수별_진단.csv`로 통합하였다.
