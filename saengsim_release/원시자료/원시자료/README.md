# 원시자료

`감히, 생심 말뭉치 통계.xlsx`는 2026년 11월 8일 기준으로 정리한 ‘감히’ 및 ‘생심’ 계열 목표 형식의 용례·출전 통계표이다. 기존 파일의 이름만 변경하였으며, 개별 용례의 출전·원문·메모는 엑셀 시트를 참조한다. 이는 전체 역사 말뭉치의 모든 문장이나 M2의 문형별 분모를 수록한 자료가 아니다.

후속 문형 분류 및 문헌 연대 판정은 `전처리` 디렉터리에 별도로 제공한다. M1·M3의 목표 용례 입력과 M2의 전말뭉치 자동 후보 구간은 자료의 출처·관측 단위·선정 기준이 다르다. 모형 적합 당시 입력은 `three_factor_logit` 디렉터리의 별도 스냅샷을 따른다.

전말뭉치 후보 추출에 사용된 자료의 식별 파일명과 원말뭉치 권리 관련 주의사항은 저장소 최상위 README를 참조한다. 파일명이나 출전 정보만으로 원말뭉치의 공식 배포 버전 또는 재배포 허가를 확인한 것으로 간주하지 않는다.

이용·재배포 조건은 저장소 최상위 README를 따른다.
